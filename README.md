# Python Practice

Beginner-friendly Python programs focused on programming fundamentals, problem-solving, and basic business applications.

## Projects

| Project | Description | Concepts |
| --- | --- | --- |
| [Calculator](projects/calculator.py) | Command-line calculator supporting four arithmetic operations | Functions, conditions, exception handling |
| [Student Grade Tracker](projects/student_grade_tracker.py) | Calculates an average score and letter grade for three subjects | Loops, functions, lists, input validation |
| [Expense Tracker](projects/expense_tracker.py) | Records expenses during a session and summarizes spending by category | Dictionaries, loops, aggregation |

These are **starter examples created for learning**, not claims of completed independent or production projects.

## Run Locally

Install Python 3, clone or download the repository, and run a script from the repository root:

```bash
python3 projects/calculator.py
python3 projects/student_grade_tracker.py
python3 projects/expense_tracker.py
```

Each script uses only the Python standard library; no extra packages are required.
